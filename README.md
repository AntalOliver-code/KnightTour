# Knight's Tour challange calculator

**Can you solve it faster than the program?**

here you can try: https://www.maths-resources.com/knights/

This program is designed to solve the **Knight's Tour** problem on a dynamically sized chessboard.

The user can enter any number to define the size of the board. For example, entering `8` will create an `8 × 8` chessboard, while entering `10` will create a `10 × 10` chessboard.

The main goal is to find a sequence of valid knight moves that allows the knight to visit **every square on the board exactly once**. The program calculates a possible solution and displays the order in which the squares are visited.

The program can be used to demonstrate **algorithmic problem solving, backtracking, and pathfinding** on different board sizes.

The program is still being optimized, it might take a while to complete bigger calculations.
